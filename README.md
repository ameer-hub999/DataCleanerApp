# 📊 Universal Data Cleaner & Auto-Formatter (Python App)

A lightweight Python micro-application built with Streamlit to clean, deduplicate, and export clean Excel/CSV data instantly.

## ✨ Features
- 🧹 *Auto-Deduplication:* Removes duplicate rows with one click.
- 🛠️ *Missing Value Handler:* Fills empty cells automatically.
- 📊 *Instant Export:* Converts raw data into clean downloadable Excel sheets.
